# Sneltoetsen

Alles met **Super** (de Windows-toets). De volledige, actuele lijst staat in
`~/.config/hypr/hyprland.conf`; hieronder staat alles op een rij.

## Applicaties

| Toets | Actie |
| --- | --- |
| `Super` + `Return` | Terminal (kitty) |
| `Super` + `D` | Applicatiemenu (wofi) — rechtsklik op het Waybar-icoon: opdracht uitvoeren |
| `Super` + `E` | Bestandsbeheer (Dolphin) |
| `Super` + `B` | Browser (Firefox) |
| `Super` + `Shift` + `B` | Google Chrome |
| `Super` + `C` | Visual Studio Code |

## Vensters

| Toets | Actie |
| --- | --- |
| `Super` + `Q` | Venster sluiten |
| `Super` + `F` | Volledig scherm (met bar erbij) |
| `Super` + `Shift` + `F` | Echt volledig scherm |
| `Super` + `Space` | Zwevend / tegels wisselen |
| `Super` + `P` | Pseudo-tegel |
| `Super` + `J` | Splitsing omdraaien |
| `Super` + `S` | Speciale workspace (kladblok) tonen/verbergen |
| `Super` + `Shift` + `S` | Venster naar de speciale workspace |
| `Super` + `←` `→` `↑` `↓` | Focus verplaatsen |
| `Super` + `Shift` + pijl | Venster verplaatsen |
| `Super` + `Ctrl` + pijl | Vensterformaat aanpassen |
| `Super` + `Tab` / `Shift` + `Tab` | Volgend / vorig venster |
| `Super` + linkermuis slepen | Venster verplaatsen |
| `Super` + rechtermuis slepen | Vensterformaat aanpassen |
| `Super` + scrollen | Vorige / volgende workspace |
| 3 vingers horizontaal | Workspace wisselen (touchpad) |

## Workspaces

| Toets | Actie |
| --- | --- |
| `Super` + `1`…`0` | Naar workspace 1–10 |
| `Super` + `Shift` + `1`…`0` | Venster naar workspace 1–10 |

## Desktop

| Toets | Actie |
| --- | --- |
| `Super` + `W` | Wallpaper kiezen (galerij met thumbnails) |
| `Super` + `Shift` + `W` | Volgende wallpaper + thema |
| `Super` + `V` | Klembordgeschiedenis (cliphist) |
| `Super` + `L` | Scherm vergrendelen |
| `Super` + `Escape` | Power-menu (wlogout) |
| `Super` + `N` | Meldingen sluiten |
| `Super` + `Shift` + `C` | Kleur prikken met hyprpicker |
| `Print` | Schermafdruk van het hele scherm |
| `Super` + `Print` | Schermafdruk van een selectie |
| `Super` + `R` | Hyprland-configuratie herladen |
| `Super` + `U` | Waybar herladen |
| `Super` + `Shift` + `R` | Waybar-kleuren vernieuwen |

In het power-menu zelf: `L` vergrendelen · `E` uitloggen · `S` slaapstand ·
`R` herstarten · `P` afsluiten.

## Media en hardware

| Toets | Actie |
| --- | --- |
| Volume-toetsen | Volume +/- (wpctl) |
| Dempen | Audio uit/aan |
| Helderheidstoetsen | Schermhelderheid (brightnessctl) |
| Afspelen / pauzeren / volgende / vorige | Muziek via playerctl |

## Waybar

| Waar | Actie |
| --- | --- |
| Klok | Links: volledige datum · rechts: kalender · scrollen: maanden |
| Wallpaper-icoon | Links: volgende wallpaper · rechts: kiezen |
| Applicatie-icoon (links) | Applicatiemenu |
| Netwerk | Netwerkverbindingen beheren |
| Bluetooth | Blueman |
| Volume | Geluidsinstellingen (pavucontrol) |
| CPU / geheugen | htop |
| Accu | Power-menu |
| Bel-icoon | Meldingen aan/uit (rechts: alles sluiten) |
| Aan/uit-icoon (rechts) | Power-menu |
